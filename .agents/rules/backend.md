# Backend Development Rules

> [!NOTE]
> Правила разработки серверной части на FastAPI и Python 3.12+.

## 1. Стек и базовые зависимости
- **Среда выполнения:** Python 3.12+.
- **Фреймворк:** FastAPI с асинхронными обработчиками (`async def`).
- **Слой данных:** SQLModel (SQLAlchemy 2.0 async + Pydantic v2).
- **СУБД:** PostgreSQL (драйвер `asyncpg`).
- **Генеративный ИИ:** `google-genai` SDK (модель Gemini 1.5 Flash) со структурированным выводом (Structured Outputs).

## 2. Структура и организация кода бэкенда
```
backend/
├── app/
│   ├── api/             # Маршрутизаторы REST API и эндпоинты
│   ├── core/            # Конфигурация (settings), безопасность (JWT), логгер
│   ├── db/              # Подключение к БД, сессии, базовые классы
│   ├── models/          # SQLModel сущности (пользователи, лобби, раунды)
│   ├── schemas/         # Pydantic DTO для запросов/ответов и Gemini схем
│   ├── services/        # Бизнес-логика (AI сервис, сервис подсчета очков, управление лобби)
│   ├── websockets/      # Менеджер соединений и обработчики real-time событий
│   └── main.py          # Точка входа приложения
```

## 3. Требования к коду
- **Асинхронность:** Все операции ввода-вывода (запросы к БД, вызовы Gemini API, WebSocket отправки) должны быть неблокирующими (`async/await`).
- **Внедрение зависимостей:** Сессии БД и контекст пользователя передаются через `fastapi.Depends`.
- **WebSocket протокол:** Все сообщения между клиентом и сервером передаются в формате JSON с обязательными полями `{"type": str, "payload": dict}`.
- **Интеграция с Gemini:** Использовать структурированные схемы (Pydantic / Structured Outputs) для генерации вопросов и фейковых вариантов ответов, исключая ручной парсинг сырого текста.

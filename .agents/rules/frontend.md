# Frontend Development Rules

> [!NOTE]
> Правила разработки клиентской части на Flutter и Dart 3.x.

## 1. Стек и платформы
- **Фреймворк:** Flutter (Dart 3.x+).
- **Целевые платформы:** Web, Desktop (Windows), Mobile (Android/iOS).
- **Стилизация:** Ретро-стилистика 8-битных аркад (pixel art, неоновые акценты, пиксельные шрифты, таймеры, аватары).

## 2. Архитектура и структура приложения
```
client/lib/
├── core/             # Сетевые клиенты, WebSocket-сервис, хранилище токенов, темы
├── models/           # Dart-модели данных и сериализация (fromJson/toJson)
├── state/            # Управление состоянием (State Management)
├── ui/
│   ├── screens/      # Экраны (Авторизация, Главное меню, Лобби, Игра, Пьедестал)
│   ├── widgets/      # Переиспользуемые UI-компоненты (Ретро-кнопки, Таймеры, Карточки ответов)
│   └── theme/        # Цветовые палитры, шрифты, стили пиксель-арта
└── main.dart         # Точка входа в приложение
```

## 3. Требования к разработке
- **Адаптивность (Responsive UI):** Использование `LayoutBuilder` и относительных размеров для комфортного отображения как на мобильных устройствах, так и на широкоформатных экранах ПК.
- **WebSocket-клиент:** Обработка обрывов соединений, повторные подключения с экспоненциальной задержкой (`exponential backoff`), строгая типизация входящих и исходящих сообщений.
- **Строгий линтинг:** Отсутствие предупреждений `flutter analyze`, соблюдение рекомендаций Effective Dart.

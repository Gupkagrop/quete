# 🛠️ Руководство по использованию MCP-серверов в проекте Quete

Добро пожаловать в автоматизированную среду разработки игры **Куэте**! Для повышения продуктивности, автоматического тестирования и надежности в вашу систему интегрировано 5 специализированных **MCP (Model Context Protocol)** серверов.

Этот файл содержит подробную инструкцию о том, как устроена эта система, как с ней работать вам и как её использует искусственный интеллект.

---

## 🧭 Что такое MCP и как это работает?

**Model Context Protocol (MCP)** — это открытый стандарт, который превращает ИИ-ассистента из простого «собеседника» в активного инженера. MCP предоставляет ассистенту безопасный набор «органов чувств» и «инструментов управления» на вашем компьютере.

### ❓ Нужно ли вам что-то делать вручную?
**Нет! Агент сам понимает, когда и какие инструменты использовать.** 
Вам не нужно учить синтаксис команд, писать API-запросы или вызывать функции. Когда вы даете задачу ассистенту на естественном языке, он анализирует доступные MCP-инструменты и автоматически вызывает их в фоновом режиме.

---

## 📦 Список установленных MCP-серверов

В вашей системе развернуты и настроены следующие серверы (в файле `C:\Users\denis\.gemini\config\mcp_config.json`):

### 1. 🗄️ MySQL MCP Server (`@f4ww4z/mcp-mysql-server`)
*   **Назначение**: Безопасный доступ к вашей локальной базе данных `quete_db`.
*   **Подключение по умолчанию**: `mysql://root@127.0.0.1:3306/quete_db` (пароль пустой).
*   **Примеры ваших запросов к ИИ**:
    *   *«Посмотри структуру таблицы `users` и скажи, какие там есть индексы»*
    *   *«Найди в базе данных пользователя с именем `Admin` и выведи его количество побед»*
    *   *«Проверь, очистил ли сборщик мусора неактивные лобби за сегодня»*

### 2. 🦊 Puppeteer MCP Server (`@modelcontextprotocol/server-puppeteer`)
*   **Назначение**: Управление браузером Chrome в фоновом режиме для автоматического тестирования интерфейса.
*   **Примеры ваших запросов к ИИ**:
    *   *«Открой страницу авторизации на локальном сервере, попробуй войти под тестовым аккаунтом и пришли мне скриншот»*
    *   *«Проверь, как выглядит форма создания лобби на экране мобильного телефона (iPhone 14)»*
    *   *«Протестируй, нет ли JavaScript-ошибок в консоли при открытии страницы игры»*

### 3. 🔑 SSH / Bash MCP Server (`ssh-mcp`)
*   **Назначение**: Безопасное подключение по SSH к вашему боевому VPS-серверу для быстрого деплоя и администрирования.
*   **Примеры ваших запросов к ИИ**:
    *   *«Подключись к серверу и покажи последние 20 строк логов Ratchet WebSocket службы `quete-websocket`»*
    *   *«Перезапусти веб-сервер Nginx на VPS»*
    *   *«Проверь, открыт ли порт 8888 в брандмауэре UFW на боевом сервере»*

### 4. 🧠 Memory Graph MCP Server (`@modelcontextprotocol/server-memory`)
*   **Назначение**: Ведение долгосрочной памяти и Графа Знаний проекта. Помогает ассистенту не забывать принятые решения, структуру ядра и связи между компонентами при переходе между сессиями.
*   **Примеры ваших запросов к ИИ**:
    *   *«Сохрани в память наше решение использовать Ratchet для сокетов и Groq для ИИ»*
    *   *«Покажи граф связей ядра игры, который ты построил»*

### 5. 🐙 Git MCP Server (`git-mcp`)
*   **Назначение**: Интеграция с системой контроля версий Git для анализа истории и изменений.
*   **Примеры ваших запросов к ИИ**:
    *   *«Посмотри историю коммитов за последнюю неделю и составь список изменений»*
    *   *«Кто последний раз менял логику валидации фейков в `game.php` и почему?»*

## ⚙️ Как изменить конфигурацию (например, пароль от БД или порт)

Все настройки серверов хранятся в одном файле на вашем компьютере:
`C:\Users\denis\.gemini\config\mcp_config.json`

Если вы измените пароль от локальной СУБД MySQL или порт подключения, откройте этот файл и отредактируйте строку подключения в блоке `mysql`:

```json
    "mysql": {
      "command": "npx",
      "args": [
        "-y",
        "@f4ww4z/mcp-mysql-server",
        "mysql://root:НОВЫЙ_ПАРОЛЬ@127.0.0.1:3306/quete_db"
      ]
    }
```

> [!IMPORTANT]
> **После любого изменения** конфигурационного файла `mcp_config.json` или установки новых серверов обязательно **полностью перезапустите ваш AI-клиент / IDE** (закройте приложение и откройте заново). Без перезапуска новые параметры и инструменты не загрузятся.

## 🛡️ Безопасность и контроль
MCP-серверы выполняются локально на вашей машине от имени вашего пользователя.
*   ИИ не может выполнить деструктивное действие без создания плана или вашего прямого контроля (согласно правилам в `GEMINI.md`).
*   Пароли и ключи доступа к VPS берутся из защищенных конфигурационных файлов и файлов ключей, которые вы контролируете.

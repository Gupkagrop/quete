# Спринт 3: Фича "Лобби и WebSockets" (День 15-21)

## Goal Description
Цель этого спринта — реализовать фичу "Фича "Лобби и WebSockets" (День 15-21)". Мы будем работать вертикально: разрабатывать бэкенд и фронтенд параллельно.

## User Review Required
Нет критических изменений, требующих предварительного ревью перед стартом спринта, помимо стандартной логики.

## Proposed Changes
Ниже описаны задачи для выполнения в этом спринте:

- **Backend:** Базовый WebSocket сервер. Управление комнатами (создать, присоединиться, передать хоста).
- **Client:** Интеграция WebSocket клиента. Экран лобби (список игроков, бейджик хоста). Синхронизация WS-стрима с UI.

## Verification Plan
1. **Автотесты:** Проверка успешности `pytest` и `flutter test`.
2. **Интеграция:** Локальный запуск `docker-compose`, бэкенда и фронтенда, ручная проверка фичи.

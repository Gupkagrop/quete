# Спринт 8: Игровой цикл — «Голосование и Подсчёт очков» (День 50–56)

## Goal Description
Цель восьмого спринта — завершить основной игровой цикл: реализовать перемешивание вариантов ответов, фазу тайного голосования, запрет на выбор собственного блефа, механику начисления очков (+1000 за правду, +500 за обман соперника), анимацию раскрытия авторов и турнирную таблицу лидеров.

---

## 1. Архитектурные решения

### 1.1 Перемешивание и анонимность в голосовании
- Сервер формирует единый список вариантов (правда + все фейки игроков/ИИ).
- Порядок вариантов случайно перемешивается (`random.shuffle`).
- В событии `start_voting` клиентам передаются только `option_id` и `text`. Имена авторов строго скрыты!
- **Правило:** игрок не может проголосовать за собственный вариант (на клиенте карточка блокируется, на сервере проверяется валидатором).

### 1.2 Математика начисления очков
- **Угадывание истины:** $+1000$ очков игроку, выбравшему правильный ответ.
- **Успешный блеф:** $+500$ очков автору фейка за **каждого** соперника, проголосовавшего за его ложь. Если вариант был объединённым — оба автора получают по $+500$ очков за каждый голос.
- **Ошибка:** $0$ очков за выбор чужого фейка.

### 1.3 Показ результатов и завершение игры
- Событие `round_results`: детальная раскладка (где была правда, кто автор каждого ответа, кто за кого голосовал, дельта очков).
- По окончании 5 раундов сессия переходит в `GAME_FINISHED` с итоговым пьедесталом почёта (1, 2, 3 места).

---

## 2. Предлагаемые изменения по файлам

### Backend (`backend/`)
- `app/models/vote.py`: SQLModel таблица `votes` (`round_id`, `player_id`, `option_id`).
- `app/services/score_engine.py`: модуль подсчёта очков и обновления турнирной таблицы.
- Логика перехода между раундами и финалом матча в `GameEngine`.

### Client (`client/`)
- `ui/screens/game/voting_screen.dart`: сетка 8-bit карточек вариантов (свой ответ подсвечен и заблокирован для выбора).
- `ui/screens/game/round_result_screen.dart`: экран раскрытия карт (поочерёдная анимация авторов и всплывающих очков).
- `ui/screens/game/leaderboard_screen.dart`: финальный пьедестал победителей с ретро-кубком.

---

## 3. План верификации
- **Pytest:** юнит-тесты формулы начисления очков (одиночные авторы, объединённые авторы, нулевые голоса), проверка блокировки само-голосования.
- **Flutter test:** виджет-тест экрана голосования и экрана результатов раунда.

# Спринт 8: Игровой цикл — «Голосование и Подсчёт очков» (День 50–56)

## Goal Description
Цель восьмого спринта — завершить основной игровой цикл: реализовать перемешивание вариантов ответов, фазу тайного голосования с защитой от множественных голосов, запрет на выбор собственного блефа, сбалансированную механику начисления очков (+1000 за правду, +500 за обман с делением между соавторами), анимацию раскрытия авторов и турнирную таблицу лидеров.

---

## 1. Архитектурные решения

### 1.1 Перемешивание и анонимность в голосовании
- Сервер формирует пул вариантов: истина + все уникальные блефы игроков и ИИ.
- Порядок вариантов случайно перемешивается (`random.shuffle`).
- В событии `start_voting` клиентам передаются только `option_id` и `text`. Имена авторов строго скрыты!
- **Правило само-голосования:** игрок не может проголосовать за вариант, автором или соавтором которого он является (на клиенте карточка блокируется, на сервере отклоняется с кодом `400 Bad Request`).

### 1.2 Ограничение на один голос (Защита от накрутки)
- В таблице `votes` действует строгое ограничение **`UNIQUE(round_id, voter_id)`**.
- Игрок имеет право отдать ровно один голос в текущем раунде. Повторные попытки голосования отклоняются.

### 1.3 Сбалансированная математика начисления очков
- **Угадывание истины:** $+1000$ очков каждому игроку, выбравшему правильный ответ.
- **Успешный блеф:** $+500$ очков за каждого поверившего соперника. Если вариант ответа был объединённым (например, 2 соавтора) — очки делятся поровну: `+500 / 2 = +250` очков каждому соавтору за каждый полученный голос.
- **Ошибка:** $0$ очков за выбор чужого фейка.

### 1.4 Раскрытие карт и завершение матча
- Событие `round_results`: детальная раскладка раунда (где была правда, кто автор каждого ответа, кто за кого голосовал, начисленные очки).
- По окончании 5 раундов сессия переходит в статус `GAME_FINISHED` с отображением пьедестала почёта.

---

## 2. Предлагаемые изменения по файлам

### Backend (`backend/`)
- `app/models/vote.py`: SQLModel таблица `votes` (`id`, `round_id`, `voter_id`, `option_id`, timestamps) с `UNIQUE(round_id, voter_id)`.
- `app/services/score_engine.py`: модуль подсчёта очков со справедливым делением для соавторов.
- Логика перехода между раундами и финалом матча в `GameEngine`.

### Client (`client/`)
- `ui/screens/game/voting_screen.dart`: сетка 8-bit карточек вариантов (свой ответ подсвечен и заблокирован для клика).
- `ui/screens/game/round_result_screen.dart`: экран раскрытия карт (поочерёдная анимация авторов и всплывающих очков).
- `ui/screens/game/leaderboard_screen.dart`: финальный пьедестал победителей с ретро-кубком.

## 3. План верификации
- **Pytest:** юнит-тесты формулы очков (одиночные авторы, объединённые авторы с делением очков), тест блокировки само-голосования, тест на ограничение 1 голоса от игрока (`UNIQUE` constraint).
- **Flutter test:** виджет-тест экрана голосования (блокировка своего варианта) и экрана результатов.

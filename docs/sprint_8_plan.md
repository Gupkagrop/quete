# Спринт 8: Игровой цикл - "Голосование и Подсчет очков" (День 50-56)

## Goal Description
Цель этого спринта — реализовать фичу "Игровой цикл - "Голосование и Подсчет очков" (День 50-56)". Мы будем работать вертикально: разрабатывать бэкенд и фронтенд параллельно.

## User Review Required
Нет критических изменений, требующих предварительного ревью перед стартом спринта, помимо стандартной логики.

## Proposed Changes
Ниже описаны задачи для выполнения в этом спринте:

- **Backend:** Рассылка перемешанных вариантов. Сбор голосов. Начисление очков (+1000 за правду, +500 за обман соперника).
- **Client:** UI голосования. Экран результатов раунда с анимацией начисления очков. Таблица лидеров.

## Verification Plan
1. **Автотесты:** Проверка успешности `pytest` и `flutter test`.
2. **Интеграция:** Локальный запуск `docker-compose`, бэкенда и фронтенда, ручная проверка фичи.

# Спринт 5: Игровой цикл - "Вопрос и Таймеры" (День 29-35)

## Goal Description
Цель этого спринта — реализовать фичу "Игровой цикл - "Вопрос и Таймеры" (День 29-35)". Мы будем работать вертикально: разрабатывать бэкенд и фронтенд параллельно.

## User Review Required
Нет критических изменений, требующих предварительного ревью перед стартом спринта, помимо стандартной логики.

## Proposed Changes
Ниже описаны задачи для выполнения в этом спринте:

- **Backend:** State Machine игры (переход в фазу вопроса). Широковещательная рассылка вопроса и старт таймера.
- **Client:** Экран чтения вопроса. Виджет синхронизированного таймера с анимацией.

## Verification Plan
1. **Автотесты:** Проверка успешности `pytest` и `flutter test`.
2. **Интеграция:** Локальный запуск `docker-compose`, бэкенда и фронтенда, ручная проверка фичи.

# Спринт 2: Фича "Авторизация и Сессии" (День 8-14)

## Goal Description
Цель этого спринта — реализовать фичу "Фича "Авторизация и Сессии" (День 8-14)". Мы будем работать вертикально: разрабатывать бэкенд и фронтенд параллельно.

## User Review Required
Нет критических изменений, требующих предварительного ревью перед стартом спринта, помимо стандартной логики.

## Proposed Changes
Ниже описаны задачи для выполнения в этом спринте:

- **Backend:** Реализация JWT Guest Auth (генерация 6-значного кода). Redis-сессии для отслеживания онлайна.
- **Client:** Экран входа (Welcome / Auth). Настройка провайдеров авторизации (Riverpod).

## Verification Plan
1. **Автотесты:** Проверка успешности `pytest` и `flutter test`.
2. **Интеграция:** Локальный запуск `docker-compose`, бэкенда и фронтенда, ручная проверка фичи.

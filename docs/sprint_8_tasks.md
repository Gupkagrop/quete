# Задачи Спринта 8: Игровой цикл — «Голосование и Подсчёт очков» (День 50–56)

### 1. Модели голосования и миграции (Backend)
- [ ] Backend: Создать SQLModel-модель `Vote` (`round_id`, `voter_id`, `option_id`) с индексом `UNIQUE(round_id, voter_id)`
- [ ] Backend: Сгенерировать и применить миграцию Alembic для таблицы `vote`

### 2. Сервис голосования и подсчёта очков (Backend)
- [ ] Backend: Реализовать алгоритм перемешивания вариантов с анонимизацией авторов
- [ ] Backend: Реализовать валидацию: запрет голосовать за собственный вариант блефа (включая если игрок является соавтором)
- [ ] Backend: Реализовать ограничение на 1 голос от игрока за раунд (проверка и DB constraint)
- [ ] Backend: Реализовать калькулятор очков `ScoreEngine` (+1000 за правду, +500/N за обман соавторами)
- [ ] Backend: Реализовать рассылку `round_results` и переход к следующему раунду или финалу

### 3. Пользовательский интерфейс голосования и результатов (Client)
- [ ] Client: Сверстать экран `VotingScreen` с карточками вариантов и визуальной блокировкой своего ответа
- [ ] Client: Сверстать экран `RoundResultScreen` с пошаговой анимацией раскрытия авторов
- [ ] Client: Создать виджет таблицы лидеров `LeaderboardScreen` с ретро-анимацией начисления очков
- [ ] Client: Сверстать финальный экран победы (пьедестал с кубком для топ-3)

### 4. Тестирование и верификация (Pre-Commit Gate)
- [ ] Backend: Написать pytest тесты для `ScoreEngine` (расчет очков при одиночных и объединенных авторах)
- [ ] Backend: Написать pytest тест на попытку проголосовать за свой блеф (ошибка 400)
- [ ] Backend: Написать pytest тест на попытку повторного голосования одним игроком в раунде
- [ ] Client: Написать widget-тест экрана голосования и подсчёта очков
- [ ] Верификация: `uv run ruff check .`, `uv run pytest`, `flutter analyze`, `flutter test`

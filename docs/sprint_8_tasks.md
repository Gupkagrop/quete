# Задачи Спринта 8: Игровой цикл — «Голосование и Подсчёт очков» (День 50–56)

### 1. Модели голосования и миграции (Backend)
- [ ] Backend: Создать SQLModel-модель `Vote` (`round_id`, `player_id`, `option_id`) в `models/vote.py`
- [ ] Backend: Сгенерировать и применить миграцию Alembic для таблицы `vote`

### 2. Сервис голосования и подсчёта очков (Backend)
- [ ] Backend: Реализовать алгоритм перемешивания вариантов с анонимизацией авторов
- [ ] Backend: Реализовать валидацию: запрет голосовать за собственный вариант блефа
- [ ] Backend: Реализовать калькулятор очков `ScoreEngine` (+1000 за правду, +500 за обман)
- [ ] Backend: Реализовать рассылку `round_results` и переход к следующему раунду или финалу

### 3. Пользовательский интерфейс голосования и результатов (Client)

- [ ] Client: Сверстать экран `RoundResultScreen` с пошаговой анимацией раскрытия авторов
- [ ] Client: Создать виджет таблицы лидеров `LeaderboardScreen` с ретро-анимацией начисления очков
- [ ] Client: Сверстать финальный экран победы (пьедестал с кубком для топ-3)

### 4. Тестирование и верификация (Pre-Commit Gate)

- [ ] Backend: Написать pytest тест на попытку проголосовать за свой блеф (ошибка 400)

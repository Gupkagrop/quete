# Спринт 9: Полировка и 8-bit дизайн (День 57–63)

## Goal Description
Цель девятого спринта — довести визуальный стиль, звуковое оформление и производительность игры до эталонного аркадного ретро-качества: процедурные CRT-сканлайны, 8-bit звуки, адаптивная верстка под все платформы (Web, Mobile, Desktop), локализация (i18n: RU/EN) и нагрузочная оптимизация WebSockets.

---

## 1. Архитектурные решения

### 1.1 Процедурный CRT-эффект (CustomPainter)
- Полноэкранный оверлей: горизонтальные линии развёртки (scanlines), мягкая виньетка по краям и лёгкое процедурное мерцание люминофора.
- Настройка производительности: переключатель в настройках «CRT-эффект: ВКЛ / ВЫКЛ» для слабых устройств и веб-браузеров.

### 1.2 Адаптивность и аркадный фрейм (Mobile-First)
- Для мобильных устройств: классический полноэкранный вертикальный интерфейс.
- Для Desktop / Web (экраны $>600$px): центрированный контейнер мобильного формата, обрамлённый стилизованным корпусом ретро-аркадного автомата.

### 1.3 Локализация (i18n)
- Поддержка двух языков: русский (RU) и английский (EN).
- Использование стандартного пакета `flutter_localizations` и `.arb` файлов.

---

## 2. Предлагаемые изменения по файлам

### Client (`client/`)
- `ui/widgets/crt_overlay.dart`: CustomPainter процедурного кинескопного экрана.
- `core/audio/retro_audio_service.dart`: воспроизведение ретро-звуков (тик таймера, клик, победный джингл).
- `l10n/app_ru.arb` и `l10n/app_en.arb`: словари локализации.
- Адаптивный лейаут `ArcadeCabinetFrame` для планшетов и ПК.

### Backend (`backend/`)
- Оптимизация пула соединений WebSocket и индексов PostgreSQL.
- Двуязычные системные сообщения и адаптация промптов Gemini под выбранный язык лобби (`language: "ru" | "en"`).

---

## 3. План верификации
- **Client test:** golden/widget тесты CRT-оверлея, тест переключения языков (i18n).
- **Backend benchmark:** профилирование задержки рассылки WS-сообщений при 50+ активных соединениях.

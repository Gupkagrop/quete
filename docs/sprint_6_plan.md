# Спринт 6: Игровой цикл - "Блеф" (День 36-42)

## Goal Description
Цель этого спринта — реализовать фичу "Игровой цикл - "Блеф" (День 36-42)". Мы будем работать вертикально: разрабатывать бэкенд и фронтенд параллельно.

## User Review Required
Нет критических изменений, требующих предварительного ревью перед стартом спринта, помимо стандартной логики.

## Proposed Changes
Ниже описаны задачи для выполнения в этом спринте:

- **Backend:** Прием ложных ответов. Валидация (защита от совпадений с правдой).
- **Client:** UI ввода фейкового ответа. Экран "Ожидание остальных игроков".

## Verification Plan
1. **Автотесты:** Проверка успешности `pytest` и `flutter test`.
2. **Интеграция:** Локальный запуск `docker-compose`, бэкенда и фронтенда, ручная проверка фичи.
